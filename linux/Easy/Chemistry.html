Enumeration

We start with the nmap enumeration.

sudo nmap -p- --open -sS --min-rate 5000 -Pn -n -vvv 10.10.11.38

We can see that there are 2 ports open.

  • TCP 22
  • TCP 5000

If we check port 5000, we can see that an HTTP web server is running.

nmap -sV -sC -p 5000 10.10.11.38

We register as a new user, and after logging in we can see that we can upload CIF files.

We can download an example CIF file and check it.

If we check the source code, we can see that example.cif is available at /static/example.cif.

When searching for vulnerabilities in CIF files, I found several CVEs, but we will continue with CVE-2024-23346.

Privilege Escalation

I checked the initial traffic and found this.

There is a server running on localhost. So I started a local port forward.

ssh -L 8080:localhost:8080 rosa@10.10.11.38

I didn't find anything important this way.

To check the server application that is running, I used this command as rosa.

curl -vvv 127.0.0.1:8080

I found out that it is running aiohttp/3.9.1.

Then I searched for a vulnerability and found CVE-2024-23334. I downloaded it and had to use the script like this.

python3 exploit.py -u [url] -f [file] -d [static directory]

To find the static directory in this case, I had to search the source code, where I found /assets.

So I modified the script like this.

python3 exploit.py -u http://127.0.0.1:8080 -f /root/root.txt -d /assets

This gave me the flag.
